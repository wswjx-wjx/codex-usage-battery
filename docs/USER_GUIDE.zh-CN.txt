Codex Usage Battery - Windows 免安装预览版

这是独立的第三方悬浮窗，与 OpenAI 无官方隶属关系。

运行条件
1. Windows 10/11，.NET Framework 4.5 或更高版本。
2. 已安装并登录 Codex，且本机可以找到 Codex 的 codex.exe。
3. 需要可用的网络连接，以便 Codex 读取当前账号额度。

使用方法
1. 完整解压 ZIP，再双击 CodexUsageBattery.exe 或 Start.cmd。
2. 激活 Codex 桌面窗口，电池会跟随显示在窗口顶部。
3. 单击电池切换 5H / 7D；鼠标悬停可查看两个周期和重置倒计时。
4. 右键电池可切换皮肤、双周期、大小、动画和提醒，也可退出。
5. 若图标隐藏，可双击 Stop.cmd 结束程序。

程序约每 30 秒通过本地 Codex 客户端查询一次额度。炫酷模式的流光是
装饰，不代表额外刷新；数据不可用或过期时会标明状态。

设置和状态保存在 %LOCALAPPDATA%\CodexUsageBattery，不要将这些文件上传。
升级同一文件夹里的旧版时，如果新数据目录还没有设置，会读取旧目录里的
settings.json，并在下次修改设置时保存到新目录；原文件不会被删除。

如果提示无法读取额度，请检查 Codex 登录和网络，并确认本机的 codex.exe
可用。自定义安装路径可通过环境变量 CODEX_USAGE_BATTERY_CLI 指向该 EXE。
如果更换登录账号后仍显示旧状态，可退出并重新启动本程序。

此预览版未进行数字签名，Windows 可能显示安全提示。请只从可信来源获取；
旁边的 SHA-256 文件可用于核对下载文件是否一致，不能单独证明程序安全。
本项目仅通过本机 Codex 客户端获取数据，不要求在本程序中输入 API 密钥。
